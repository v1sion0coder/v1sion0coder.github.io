# V1SION — Digital Studio

Portfolio site of V1SION Digital Studio: art-directed websites for cafés, bakeries and independent places.

Live at https://v1sion0coder.github.io

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```

Built with Vite, Three.js and GSAP. The 3D aperture in the hero is made in code (no model files).
Fonts: Syne and JetBrains Mono (SIL Open Font License), bundled via Fontsource.

Deploy: `npm run deploy` builds the site and pushes `dist/` to the `gh-pages` branch, which GitHub Pages serves.
