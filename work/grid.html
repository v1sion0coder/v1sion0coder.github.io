Grid

Gluten-free waffle café

A small café where every waffle is gluten-free. The goal: booking a table should take three taps, and the first screen should already feel warm.

Status
Concept, self-initiated, fully built
Role
Design and development, by v1sion
Languages
English
Year
2026

01The concept

“Build yours”. A waffle is a grid you fill. The homepage hero is a 3D waffle the visitor can spin and dress with toppings (syrup, butter, cream, berries, pistachio, sugar), so the very first interaction already feels like ordering at the counter.

02Who it's for

Families, friends and people with coeliac disease or gluten intolerance, for whom “100% gluten-free” is the reason to come. Small groups that want to be sure of a table at the weekend.

03UX decisions

  • Booking starts from the day and the number of guests, then shows only times that are really free.
  • Allergies and diets can be added to the booking with one tap each.
  • Every booking gets a private link to change or cancel it, which keeps tables free for others.
  • When a day is full, guests can join a waitlist instead of leaving.

04What works

  • Live table booking with real free times, 60 days ahead, groups by phone
  • Private change / cancel link for every booking
  • Waitlist for full days
  • Staff admin: bookings by day and week, walk-ins and phone bookings, close a day for a private event
  • Menu editing and booking stats; owner and staff roles with two-step sign-in

05How it's built

  • Three.js for the interactive waffle with live toppings
  • Node.js + Express server with a SQLite database
  • Strict content security policy, rate limits, hashed passwords

06On the phone

About this project. Grid is a concept: designed and built by V1SION as a proposal for an existing gluten-free waffle café in Tallinn, not a commissioned job.
